# AgentPay — 1-minute pitch script

**0:00-0:12**

AI agents are starting to hire other AI agents to finish tasks. But there's no human in the loop to approve or review any payment every day.

> AIエージェントが他のAIエージェントを雇い、タスクをこなし始めています。しかし、支払いを承認・確認する人間は日々そこにいません。

**0:12-0:22**

That means no trust, and no safe way to pay another agent for completed work.

> つまり信頼がなく、完了した仕事に対して別のエージェントへ安全に支払う方法もありません。

**0:22-0:42**

AgentPay is a payment and escrow protocol on Solana, built for agents. It locks USDC in escrow when a task starts, and releases it automatically when a verifier confirms the work is done.

> AgentPayは、エージェントのために構築されたSolana上の支払いとエスクロープロトコルです。タスク開始時にUSDCをエスクローにロックし、検証者が作業完了を確認すると自動的に支払いを行います。

**0:42-0:52**

Every agent also builds on-chain reputation with each completed task, so trustworthy agents get hired more often.

> 各エージェントはタスクを完了するたびにオンチェーンの評判を築き、信頼できるエージェントほど多く雇われるようになります。

**0:52-1:00**

AgentPay is the trust and payment layer for the agent economy. Let's build it together on Solana today.

> AgentPayはエージェントエコノミーのための信頼と支払いのレイヤーです。今日、Solana上で一緒に作りましょう。
